# Japan A717C DMA helper tail composition

## Resumed original state

This result extends the paired A717C→A6112→A5FC4 execution to the next
original calls. First, the prefix probe was rerun over 23,328 distinct cases
twice, adding R6 values `0`, `1`, and `0xFFFFFFFF`; A717C copies R6 to R8,
which selects later signed branches. Each prefix returns from A5FC4 to
`PC=PR=0x060A71C0` after 79 instructions. The two private boundary reports in
`execution-178/` are byte-identical (SHA-256
`6168725611c858f09c082c8ac47f788d08e21f64cf2702b4c602bc2c0073929b`); the
result digest is
`1cacfcc2968f8412bbb78120b89867742b567b1996e23f639dac7e965de99408`.

The second probe restores each selected boundary's complete R0–R15/SR state and
the exact recorded stack writes over captured frame-1200 WorkRAM-H. It then
executes original A717C from `0x060A71C0` through A600C, the A595B6 shift leaf,
and A6100, stopping at `0x060A723C`, immediately before the A5F98 call. This is
a serialized continuation across a recorded CPU boundary, not one uninterrupted
interpreter process. It covers 1,728 selected boundary states twice; the two
private reports in `execution-179/` are byte-identical (SHA-256
`36755d13e898c7d60885fe87d6cbb9f6bd5f78477e4186bd50e54a1058340bf4`), with
result digest
`31a11d84b9ab0eedbaf7d3c00880a4540833579ab56bb9238942e0dd062ef92b`.
Recorded tail paths take 153–159 SH-2 instructions, according to R8/stack-word
branch results. Replacing the original A600C JSR at `0x060A7232` (`0x430B`)
with NOP is rejected by the PC-path contract (44 rather than 155 instructions
in the selected control case).

Across the selected cases, A717C constructs descriptor flags `0x2FF` and
descriptor words derived from R7, R10, R8, the entry stack word, and constants
`0x800`/`0x200`. The original A600C/A595B6 path emits three DMAC writes and one
CHCR write; original A6100 then sets CHCR.DE. No DRCR write occurs in these
selected descriptor states. The MMIO values are modeled from the documented
SH7604 register contract, not generated by an active Saturn DMA engine.

## Limits and continuation

Both probes use constructed registers, caller stack values, CHCR/DMAOR and a
documented register model. They do not establish natural A717C callers, real DMA
activity/timing, cache-purge side effects, gameplay role, or Saturn hardware
parity. The tail stops before the A5F98 call and before the A717C outer epilogue.
Next, trace the original purge effect and continue through the remaining return
path and natural caller dataflow. All-code/all-assets recovery remains open.

The first tail attempt (`execution-179/tail-a.json`) failed when the fence
omitted the saved R7 reads at local SP and SP+4; the accepted paired run uses
the corrected exact stack-read boundary.
