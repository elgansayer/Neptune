# Japanese kernel A600C DMAC channel setup

The original Japanese kernel bytes at `0x060A600C` execute through the
`RTS` delay slot at `0x060A60E8`. With flag bit 3 set, A600C calls the original
leaf at `0x060959B6`; its three `SHLL2` instructions and `SHLL8` return delay
slot transform descriptor word `+12` by `2^14`. A600C saves and restores PR
around its work and returns the original descriptor pointer in R4. When the
descriptor's `0x100` flag is set, R5 becomes the byte register address
`0xFFFFFE71 + channel`; R0 returns the descriptor mask's `0x80` bit.

The probe executed 16,384 constructed cases twice each: every 10-bit flag mask
0–`0x3FF`, both channel indices, four descriptor patterns and initial CHCR
values 0 and 3. Its exact PC fences cover every branch and the A595B6 call and
both delay slots. It validates descriptor and literal reads, stack/linkage,
selected SAR/DAR/TCR/CHCR writes, and the optional DRCR byte write. Register
addresses and sizes follow the [SH7604 Hardware Manual, §9.1.4 and §§9.2.1–9.2.6](https://antime.kapsi.fi/sega/files/sh7604.pdf#page=250):
SAR/DAR/TCR/CHCR are longword registers, while DRCR0/1 are byte registers;
CHCR TE is write-zero-to-clear. The bounded fixture models these register
accesses only and does not run a DMA transfer engine or its timing.
